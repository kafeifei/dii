# DII · 暗夜深渊

浏览器里跑的单机 ARPG，玩法向《暗黑破坏神 2》看齐。TypeScript + Three.js，画面是低多边形 3D 加固定斜俯视正交相机。所有模型、贴图、图标、音效都是代码实时生成的，没有外部美术资源。

## 运行

```bash
npm install
npm run dev
```

打开终端里打印的地址即可。地址后加 `?dev` 会跳过标题页直接开新档，并且在页面不可见时也继续跑模拟（方便自动化测试）。

## 操作

| 操作 | 按键 |
| --- | --- |
| 移动 / 攻击 / 拾取 / 交互 | 左键（按住持续移动或持续攻击） |
| 原地攻击 | Shift + 左键 |
| 右键技能 | 右键 |
| 技能快捷键 | Q W E R（点技能栏可更换；在技能树上悬停时按 Q/W/E/R 直接绑定） |
| 腰带药剂 | 1 2 3 4 |
| 背包 / 角色 / 技能树 | I / C / T |
| 回城传送门 | P |
| 全屏地图 | Tab |
| 缩放 | 滚轮 |
| 静音 | M |
| 菜单 / 关闭面板 | Esc |

背包里：右键使用药剂或直接装备；Ctrl+左键在商店里快速出售、在储物箱里快速存取；把符文拿起来点到有孔装备上就是镶嵌，符文顺序对上就会变成符文之语。

## 已实现

- **职业**：圣殿骑士，三系 15 个技能（战斗技能 / 进攻光环 / 防御光环），有前置技能和协同加成；光环同时只能开一个
- **世界**：营地（商人、储物箱、传送点）+ 无限往下的随机地牢，每 4 层换一种主题（墓穴、洞穴、冰窖、深渊），第 4、8、12… 层有首领
- **怪物**：10 种普通怪 + 3 个首领；精英怪群、带随机词缀（特别强壮、火焰强化、闪电强化等）的暗金怪和随从；小鬼萨满会复活同伴，小鬼会在同伴死后逃跑
- **装备**：普通 / 优质 / 有孔 / 魔法 / 稀有 / 暗金 / 套装 / 符文之语；约 50 种底材、100+ 词缀、16 件暗金、2 套套装、12 个符文、7 个符文之语；魔法装备几率（MF）带 D2 式递减
- **系统**：格子背包、纸娃娃装备栏、腰带、商店买卖、储物箱、传送点、回城门、经验与升级加点、受击硬直与格挡、元素抗性、冰冻减速、中毒、偷取生命、致命一击、本地存档
- **表现**：光照半径与动态火把、可穿透的遮挡墙、打击停顿、屏幕震动、血迹、碎骨与冰冻碎裂死亡、粒子特效、小地图与全屏地图、WebAudio 合成音效与环境音

## 目录

```
src/
  data/     数据表：底材、词缀、暗金/套装/符文、怪物、技能、属性
  items/    装备生成、格子背包、提示框
  world/    瓦片地图、A* 寻路、地牢与营地生成
  game/     模拟层：角色、怪物 AI、战斗结算、技能、关卡、存档（不依赖渲染）
  render/   Three.js 渲染：程序化角色骨骼、道具、贴图、粒子与特效
  ui/       DOM 界面：HUD、各面板、图标绘制、小地图
  audio/    WebAudio 合成音效
tools/
  play.mjs  无头 Chromium 剧本运行器（截图、读取游戏状态）
  bot.mjs   数值平衡机器人：自动打怪下楼，统计每层耗时、等级和死因
```

## 测试工具

需要先 `npm run dev`，然后：

```bash
node tools/play.mjs tools/bot.mjs --url "http://localhost:5174/?dev"
```

`DEPTH` 和 `MINUTES` 环境变量控制机器人打到第几层、最多模拟多少分钟（游戏内时间，快进运行）。
