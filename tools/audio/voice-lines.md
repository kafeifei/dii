# 主角台词

圣殿骑士和法师的提示语，学暗黑 2 里主角的那些短句（背包满了、法力不够、用不了这件东西、进了危险的地方……），措辞是新写的。两人说同一套场合，各说各的话：

- **圣殿骑士**：男声，低沉、稳重，话少，带一点信仰的口吻（「圣光」）。音色 Brian。
- **法师**：女声，冷静、自信，偶尔有点傲气。音色 Lily。

`tools/audio/list.mjs` 从下表读台词，`node tools/ai-audio.mjs --budget <积分>` 把它们生成成 `voice.<职业>.<键>`（如 `voice.paladin.no_mana`）；改了哪句，下次带 `--budget` 运行就只重新生成那一句。键和场合也登记在 `src/audio/sounds.ts` 的 `HERO_LINES`，两边要一致。台词写在「」里，标点也算字数，每个字 1 积分。

| 键 | 什么时候说 | 圣殿骑士 | 法师 |
| --- | --- | --- | --- |
| `bag_full` | 背包放不下捡起的东西 | 「行囊已经满了。」 | 「没地方放了。」 |
| `cant_carry` | 再也拿不下（腰带满了、金币到了上限） | 「我带不了更多了。」 | 「再多我可拿不动。」 |
| `cant_use` | 这件东西主角用不了（别的职业的、放不进那一格） | 「这东西不是给我用的。」 | 「这种东西，我用不上。」 |
| `too_weak` | 力量或敏捷不够装备它 | 「我的力量还不足以驾驭它。」 | 「它太沉了，不适合我。」 |
| `low_level` | 等级不够装备它 | 「历练尚浅，还用不了它。」 | 「还不到时候。」 |
| `no_mana` | 法力不够施放技能 | 「我的法力不够。」 | 「法力不足。」 |
| `no_gold` | 金币不够买、修理或赌博 | 「我的金币不够。」 | 「钱不够。」 |
| `cant_here` | 在这里做不了（比如营地里施法） | 「在这里不行。」 | 「这里施展不开。」 |
| `no_potion` | 按了腰带上空着的那一格 | 「药剂用完了。」 | 「药水没了。」 |
| `level_up` | 升级 | 「圣光赐我更多力量。」 | 「我的力量又精进了。」 |
| `low_health` | 生命掉到很低 | 「我伤得很重……」 | 「伤得不轻……」 |
| `poisoned` | 中毒 | 「毒已入血。」 | 「我中毒了。」 |
| `item_breaking` | 装备的耐久快耗尽 | 「我的装备快撑不住了。」 | 「装备快坏了。」 |
| `unique` | 捡起一件暗金物品 | 「这是一件非凡之物。」 | 「哦？这件倒是有点意思。」 |
| `set_item` | 捡起一件套装物品 | 「这件东西……似乎还有同伴。」 | 「这件该是成套的。」 |
| `rune` | 捡起一枚符文 | 「一枚古老的符文。」 | 「符文……上面的力量还在。」 |
| `enter_wild` | 走出营地，进入野外 | 「荒野之中，处处杀机。」 | 「荒野可不讲情面。」 |
| `enter_dungeon` | 第一次走进地下城 | 「黑暗在下面等着我。」 | 「下面的空气……不太对劲。」 |
| `night_falls` | 野外入夜 | 「夜色降临，邪物要出来了。」 | 「入夜了，正好。」 |
| `evil_here` | 走进危险的区域 | 「我感到了邪恶的气息。」 | 「这里的魔力很邪门。」 |
| `lair` | 找到任务里那个邪恶的巢穴 | 「这里就是那邪恶的巢穴。」 | 「就是这里了，邪恶的巢穴。」 |
| `graveyard` | 走进墓地、埋骨之地 | 「这里的死者不得安息。」 | 「死人也不肯安分。」 |
| `many_foes` | 一大群怪物冲过来 | 「它们成群结队地来了。」 | 「来得正好，一起上吧。」 |
| `boss_near` | 头目发现了主角 | 「来吧，恶徒。」 | 「终于来了个像样的。」 |
| `boss_dead` | 打倒头目 | 「邪恶已被涤净。」 | 「不过如此。」 |
| `area_clear` | 清空了一个区域 | 「此地已经肃清。」 | 「清理干净了。」 |
| `quest_done` | 完成任务 | 「使命完成了。」 | 「事情办妥了。」 |
| `waypoint` | 激活新的传送点 | 「传送点，记下了。」 | 「传送点，省了不少路。」 |
| `shrine` | 触碰神龛 | 「愿这力量护佑我。」 | 「这股力量，我收下了。」 |
| `back_in_town` | 回到营地 | 「总算可以歇口气了。」 | 「回营地歇一歇。」 |
