# M2a 的决定（2026-10-29）

M2a 开工前做了一轮调研（地图、地下城、怪物、任务和佣兵、美术五份报告，外加一份复核），里面提的问题按下面做。总原则：照原版（D2R 2.7、D2MOO）；和「存档不丢、不复制物品」冲突时，守规则。名字已经定稿（claude/names 58a640c）：营地叫流离者营寨，佣兵叫流离者斥候，柯霞 / Khassia、亚喀蕾 / Akarelle、绯鸦、列石荒野、葬骨荒冢、墓窖、安魂陵、石窟一层/二层、腐羽鸦/腐羽鸦窠、望月部族、晦影游猎者、罗喀倪秀、霜鸦、摧骨者——一律从改名表读，不写死。

## 地图
- 列石荒野：照 D2 只在北边和西边用悬崖封边（替换树林，不挡路）；悬崖先用现有岩石贴图程序化生成。地下通道的洞口开在悬崖上，M2a 里是关着的入口，走近提示还没有开通。
- 凯恩之石：M2a 只摆景物，加罗喀倪秀；传送门和发霉的书留到 M2b，和任务一起做。
- 葬骨荒冢：程序化墓园，铺满边框内的 4×6 个单元（和 8×8 单元网格对齐），墓窖、安魂陵两个入口在里面。
- 区域之间空地上的树限制在离区域 32 格以内。
- BUILT 和传送点面板按 D2 的区域编号排；bot 和 bench 的路线改成按连接图找路。
- 列石荒野新做一张碎石地贴图。

## 地下城
- 新的迷宫生成器照 D2MOO 的 DrlgMaze；尺度和大地图一样 1.25 倍（洞穴每格 30，墓窖每格 10）。
- 邪秽巢穴换成同一个生成器出的原版 3 间 L 形洞（巢穴现有的检查都要还成立）。
- 墓窖和安魂陵照原版随难度变大（12/24/36 间）。
- 洞里照原版不点火把，只靠角色身上的光；墓窖保留火把。截图要确认手机上看得清。
- 第一幕洞穴新做一对土褐色贴图（地面、墙）。
- 物件照原版密度：棺材（18% 冒出僵尸或骷髅）、游侠尸体、井、箱子、木桶、神龛；上锁的箱子（要钥匙）照做。箱子陷阱、爆炸桶、木桶的陷阱怪放到 M2a 收尾，做不完就记进已知缺口。
- 超级宝箱：石窟二层用 580 闪光规则，安魂陵用 397 规则。
- 洞里的小动物（rat、bat）不做。

## 怪物
- 选目标严格照 D2：在主角和佣兵里取最近的；主角在营地或离怪 55 子格以上时都不算。
- 绯鸦照 D2MOO：僵尸在她脚下爬起，累计上限 8/10/12；急射只射一支箭；她死时 35 子格内的亡灵 1–5 秒后倒下，不给经验、不掉东西；raven2 照 D2MOO 不射。
- 只认葬骨荒冢里生成的绯鸦（照 D2 给她挂任务记录），试炼场的绯鸦不算任务。
- 怪物格挡照原版做（带盾的枯骸 10%）。
- 新模型（羊头人、腐羽鸦、鸟巢）直接用；绯鸦先用堕落女武士加弓占位，再单做她的模型。

## 佣兵和任务
- 雇佣等级照 D2MOO（段等级 + 0…4，不超过主角）；8 级门槛照 D2MOO。
- 雇新佣兵时，旧佣兵的装备自动还给主角：背包 → 个人储物箱 → 储物箱旁边，逐件清点，先弹确认说明这一点（D2 是直接删掉，违反规则 1）。
- 已有佣兵时完成任务：照 D2，不再给。
- 主角死时佣兵也死，复活要花钱：照 D2。
- 领奖要站在绯鸦的地块或相邻地块：照 D2（含斜对角）。
- 弓手能用亚马逊弓：照 D2R 2.7（equivalentcharclass=ama）。
- 佣兵技能用技能表达式求值器算（最小子集提前到 M2a，A5 接着用），不手写近似。
- 主角的光环作用到佣兵（照原版）。法师的附魔等 A5 有了再说。
- 佣兵离主角远时，她附近的怪也要动（两边取并集）。
- 佣兵不配台词（原版只有受击和死亡声）。

## 美术
- 佣兵用营地女游侠 npc_rogue（原版 RG），补射箭、受击、死亡动作。
- 柯霞先用 npc_rogue 染色、改体型，和佣兵分得开；她自己的模型等 M3 的 NPC 批次。
- 绯鸦单做 Meshy 模型（原版 CR，有自己的头和腿）。
- 列石、岩洞口、大石块这些静态道具用 Tripo Studio 的订阅积分（要用户在终端里登录一次）；登录前先用现有模型顶着。

## 声音
- 加三个怪物声音类别：bird、goat、rogue（女声），加鸟巢孵化、绯鸦召唤两个单次音效；加墓窖的环境（环境声循环 + 一首墓穴音乐，音乐在 box 上用 ACE-Step 生成）。花 ElevenLabs 之前先查剩余额度。
- 柯霞和亚喀蕾的 M2a 台词先写好放进审阅页，M2a 收尾时再配音。

## 体积、性能、发布
- 发布包体积按内部站点的真实上限 52,428,800 字节（50 MiB）留余量；超了先压贴图和模型，音乐降码率要用户先听。
- 每加一块区域跑一次 bench；M2a 试玩时请用户在 iPhone 上量一次。
- 回滚兜底：读档时进不去存档里的区域，就回营地。
